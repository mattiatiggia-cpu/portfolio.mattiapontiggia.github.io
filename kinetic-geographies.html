Kinetic Geographies – Artificial A(I)rchive project explores the relationship between fashion, memory and technology, drawing inspiration from Calvino’s "Invisible Cities" and Gianfranco Ferré’s archive.

The process combines archival research, analysis of light and movement using TouchDesigner and experimentation with AI tools to generate new lines, shapes and volumes.

The ideas are then reinterpreted through three cities (Eutropia, Zora, Eudossia), transforming the original garments into new hybrid objects that bridge fashion and storytelling. The result is a collection that combines an algorithmic approach with design sensibility, where memory and innovation interact to create new formal possibilities.
